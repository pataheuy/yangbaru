Panduan Menambahkan Heading

Cara termudah untuk menambahkan Heading di Pufutara Doc adalah menggunakan Dropdown Gaya Paragraf yang terletak di toolbar atas (sebelah pilihan jenis font). Cukup blok baris teks yang diinginkan, kemudian pilih opsi:

  • Heading 1: Untuk judul utama bab besar.
  • Heading 2: Untuk sub-judul bagian.
  • Heading 3: Untuk sub-bagian kecil.

Setelah diubah, heading tersebut otomatis terdeteksi di Sidebar Kiri (Daftar Isi) sebagai navigasi dinamis!

Cari dan Ganti Kata

Tekan tombol pencarian di toolbar atau tekan pintasan tombol Ctrl + F pada keyboard Anda untuk mencari kata tertentu dan menggantinya langsung.

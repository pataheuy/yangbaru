Cara Install
1
Download dan ekstrak file extension.zip ke folder mana saja.
2
Buka Chrome dan navigasi ke chrome://extensions.
3
Aktifkan Developer mode di pojok kanan atas.
4
Klik Load unpacked lalu pilih folder hasil ekstrak tadi.
5
Extension siap. Login ke situs mana saja — akun otomatis tersimpan.
